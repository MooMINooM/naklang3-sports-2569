# สนามกลาง นากลาง 3 — ติดตั้งกับ Google Sheets

1. สร้าง Google Sheets เปล่า แล้วเปิด **ส่วนขยาย → Apps Script**
2. นำเนื้อหา `Code.gs` มาแทนโค้ดเดิม เพิ่มไฟล์ HTML ชื่อ `Index` และ `Bridge` แล้ววางเนื้อหาจากไฟล์ชื่อเดียวกัน
3. ที่ท้ายไฟล์ `Code.gs` เพิ่ม `function initializeSports() { setupSports_(); }` ชั่วคราวแล้วบันทึก เลือก `initializeSports` จากตัวแก้ไข กด Run และอนุญาตให้เข้าถึงชีต ตรวจว่ามีแท็บ Matches, Fields, Schools และ Settings แล้วลบฟังก์ชัน `initializeSports` และบันทึกก่อนเผยแพร่เว็บ
4. เปิด Project Settings → Script properties แล้วเพิ่ม `SPORTS_ADMIN_KEY` เป็นรหัสสุ่มยาวอย่างน้อย 20 ตัวอักษร ส่งรหัสให้เฉพาะผู้จัด และเก็บไฟล์ชีตเป็นส่วนตัวเพื่อให้ผู้ชมอ่านผ่านเว็บเท่านั้น
5. เลือก Deploy → New deployment → Web app → Execute as Me แล้วเลือกผู้เข้าถึงตามกลุ่มเป้าหมายที่บัญชี Google อนุญาต นำ URL ที่ลงท้ายด้วย `/exec` ไปใช้ เมื่อแก้โค้ดให้อัปเดตเวอร์ชันของ deployment เดิม

ตั้ง URL `/exec` ใน `sports-api.js` ให้ตรงกับการเผยแพร่ หน้า `admin.html` ใช้รหัสผู้จัดเพื่อเพิ่มคู่ แก้ไขคิว บันทึกผล และเผยแพร่ ส่วนหน้าผู้ชมแสดงเฉพาะคู่ที่เปิดแสดง

ไฟล์ `Bridge.html` สื่อสารกับหน้า GitHub Pages ที่ `https://moominoom.github.io` หากเปลี่ยนโดเมน ให้แก้ `pagesOrigin` และอัปเดตเวอร์ชันการเผยแพร่

- Matches เก็บคู่ ตารางสนาม ผล และสถานะเผยแพร่ เพิ่มและแก้ไขจากเว็บเพื่อให้ตรวจคิวก่อนบันทึก
- Fields และ Schools เก็บสนามและรายชื่อโรงเรียน Settings เก็บขอบเขตเวลาทดลอง แก้ได้จากชีต
- `convertDay` และ `convertTime` กำหนดเวลาที่สนามฟุตบอล F2 และ F3 เปลี่ยนจากประถมต้นเป็นสนามร่วมประถมปลาย/มัธยม หลังจบการแข่งและปรับสนามแล้ว ถ้าเว้นว่างจะใช้เป็นสนามประถมต้นตลอด
- กำหนดคู่แข่งและสาย A–C จากผลจับสลากด้วยตนเอง มัธยมเลือกรอบพบกันหมด ผู้จัดตรวจรายชื่อนักกีฬาที่ลงตะกร้อ/เปตองพร้อมกัน และยืนยันคู่เข้ารอบตามกติกาของงาน
- คะแนนในหน้าอันดับเป็นเบื้องต้น ฟุตบอลชนะ 3 เสมอ 1 กีฬาอื่นเรียงจากจำนวนชนะ ฉบับนี้แสดงอันดับร่วมเมื่อคะแนนเท่ากัน ให้คณะกรรมการยืนยันเกณฑ์เสมอและการเทียบรองแชมป์ต่างกลุ่มก่อนประกาศอันดับอย่างเป็นทางการ

เอกสารการเผยแพร่ Web app ของ Google — https://developers.google.com/apps-script/guides/web
