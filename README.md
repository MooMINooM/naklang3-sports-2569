# Naklang 3 Sports 2569

เว็บไซต์จัดการแข่งขันกีฬานักเรียน ศูนย์เครือข่ายคุณภาพการศึกษานากลาง 3 ประจำปีการศึกษา 2569

## สถาปัตยกรรม
- **GitHub Pages**: หน้าเว็บสาธารณะ (HTML/CSS/JavaScript)
- **Google Apps Script**: อ่านข้อมูลสาธารณะ / ตรวจรหัสผู้ดูแลและบันทึกข้อมูล
- **Google Sheets**: ฐานข้อมูลโรงเรียน ทีม รายการแข่งขัน สนาม และคู่แข่งขัน
- ไม่บันทึกรหัสผ่านหรือข้อมูลนักเรียนรายบุคคลใน repository

> หมายเหตุ: โค้ดชุดนี้เป็นระบบเริ่มต้นที่สร้างใหม่โดยอิงข้อกำหนดการแข่งขัน ไม่ใช่การ export ซอร์สจากเว็บ ChatGPT Site เดิม เพราะยังไม่ได้รับซอร์สเว็บไซต์ดังกล่าว

## การเปิดใช้ฐานข้อมูล
1. สร้าง Google Sheet ใหม่ (ตั้งชื่อ เช่น `Naklang3 Sports 2569`)
2. เปิด **Extensions → Apps Script** แล้ววางโค้ดจากไฟล์ [apps-script/Code.gs](apps-script/Code.gs)
3. Run ฟังก์ชัน `setupSheets` หนึ่งครั้ง และอนุญาตสิทธิ์เมื่อ Google ขอ
4. Run ฟังก์ชัน `setAdminPassword` และกรอกรหัสผ่านที่คาดเดายาก (เก็บเฉพาะ hash ใน Script Properties)
5. Apps Script → **Deploy → New deployment → Web app** → Execute as **Me** → Who has access **Anyone** → Deploy แล้วคัดลอก URL ที่ลงท้าย `/exec`
6. แก้ไฟล์ [config.js](config.js) นำ URL ไปใส่ใน `apiUrl`; อย่าใส่รหัสผ่านในไฟล์
7. GitHub repository → **Settings → Pages → Deploy from a branch → main → /(root) → Save**
8. เปิดเว็บที่ `https://moominoom.github.io/naklang3-sports-2569/` และทดลองอ่านข้อมูล / เพิ่มทีม / เพิ่มคู่ / บันทึกผล

## การใช้งาน
- ผู้ชมดูโปรแกรม ผล และตารางคะแนนได้โดยไม่ต้องเข้าสู่ระบบ
- ผู้ดูแลกรอกรหัสเฉพาะตอนบันทึกเพิ่มหรือแก้ไข
- ตั้งต้นชีต **Schools**, **Teams**, **Events**, **Venues**, **Matches**; ไม่มีข้อมูลแมตช์สมมุติ
- ระบบตรวจสนามชนกัน และคิวฟุตบอล/วอลเลย์บอลรุ่น-ประเภทเดียวกัน โดยเว้นระยะ 15 นาที
- ตารางอันดับเป็นการคำนวณเบื้องต้นจากผลที่กรอก (3 คะแนนชนะ / 1 เสมอ / 0 แพ้) ต้องตรวจเทียบระเบียบจริงก่อนใช้ตัดสิน

## ข้อจำกัด / ความปลอดภัย
- การเผยแพร่ Apps Script ให้ Anyone หมายถึง endpoint อ่านข้อมูลสาธารณะ; คำสั่งเขียนตรวจรหัสผ่านฝั่ง Apps Script
- เปลี่ยนรหัสผ่านได้ด้วย `setAdminPassword`; ห้ามนำรหัสไปไว้ใน repository หรือ URL
- เหมาะกับงานขนาดเล็ก ไม่ใช่ระบบคะแนนความถี่สูงหรือฐานข้อมูลธุรกรรม
- **ห้ามใส่ข้อมูลส่วนบุคคลของนักเรียน** เช่น เลขบัตรประชาชนหรือรายละเอียดสุขภาพ ลงในชีตที่แสดงต่อสาธารณะ
- การส่งคำสั่ง POST ข้ามโดเมนผ่านเบราว์เซอร์เป็นแบบ no-cors จึงใช้การอ่านข้อมูลใหม่เพื่อตรวจสอบผล ไม่ควรกดส่งซ้ำหากยังตรวจไม่พบรายการ
