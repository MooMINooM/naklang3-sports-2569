- หน้าผู้จัด https://moominoom.github.io/naklang3-sports-2569/admin.html

GitHub Pages ให้บริการหน้าเว็บ และ Supabase โปรเจกต์ SchoolWeb เก็บข้อมูลกับประมวลผลผ่าน Edge Function `naklang3-sports` กำหนดปลายทางใน `config.js` ใช้ publishable key สำหรับหน้าเว็บ ส่วนกุญแจฐานข้อมูลอยู่ในสภาพแวดล้อมของ Edge Function

## ข้อมูลการแข่งขัน

ตาราง `sports_naklang3_*` เก็บข้อมูลแยกสำหรับการแข่งขันนี้ ต้นฉบับ Excel อยู่ใน `sports_naklang3_imports` พร้อม SHA-256 และเวอร์ชันไฟล์ ตารางแข่งขันเริ่มจากข้อมูล Excel 216 คู่ 20 รายการ 144 ช่องทีม และ 11 สนาม โดยคงเวลาตามต้นฉบับ

ทะเบียนเลขทีมและลำดับตัดสินอยู่ใน `sports_naklang3_runtime` รหัสผู้จัดเก็บเฉพาะ SHA-256 และใช้ผ่าน HTTPS ผู้ชมอ่านเฉพาะคู่ที่เผยแพร่ การเขียนใช้ Edge Function และธุรกรรมตรวจเวอร์ชันเพื่อป้องกันการบันทึกทับกัน

กำหนดชื่อโรงเรียนและลิงก์โลโก้ในเมนู «กำหนดเลขทีมโรงเรียน» ของแอดมิน เลขจับสลากกลางผูกกับโรงเรียนแต่ละแห่ง ฟุตบอลและวอลเลย์บอลรวมหนองด้วงวังประทุมกับซำขอนแก่นวิทย์ที่เลขน้อยกว่า แล้วยุบเลขที่มากกว่าและเลื่อนเลขถัดไปขึ้นหนึ่งตำแหน่ง ตะกร้อและเปตองใช้เลขจับสลากเดิม ผลวอลเลย์บอลและตะกร้อบันทึกแต้มรายเซต แข่งชนะ 2 ใน 3 เซต ระบบสรุปผู้ชนะและคำนวณทีมเข้ารอบอัตโนมัติ กรณีอันดับเสมอกันใช้เมนูตัดสินอันดับ

## ดูแลระบบ

ซอร์ส Edge Function อยู่ใน `supabase/functions/naklang3-sports` กติกาใช้ร่วมกันใน `rules.js` SQL ของส่วนเชื่อมระบบอยู่ใน `supabase/runtime.sql` ซึ่งใช้ต่อจากตารางที่นำเข้า Excel แล้ว ตั้ง `verify_jwt=false` เพราะฟังก์ชันตรวจรหัสผู้จัดเองก่อนอนุญาตให้แก้ไขข้อมูล

หากหมุนรหัสผู้จัด ให้คำนวณ SHA-256 ของรหัสใหม่แล้วแก้เฉพาะ `admin_key_hash` ใน `sports_naklang3_runtime` ผ่านผู้ดูแลฐานข้อมูล ห้ามใส่รหัสผู้จัดหรือ secret key ลงในไฟล์สาธารณะ

## การสุ่มสาย

ปุ่ม «สุ่มสายแบบกระจายคู่แข่ง» จะสุ่มและเปรียบเทียบความถี่ที่โรงเรียนร่วมสายข้ามรายการทั้งหมด โดยเก็บ seed และผลก่อน–หลังใน `sports_naklang3_runtime.config.groupDraw` ยอมให้คู่เดิมร่วมสายซ้ำและให้คะแนนต้นทุนสูงขึ้นเมื่อซ้ำบ่อยขึ้น ผลสุ่มจับหมายเลขทีมเข้ากับช่องเดิมของตาราง โดยคงรหัสคู่ วัน เวลาเริ่ม เวลาจบ สนาม และจำนวนทีมต่อสาย ผลคำนวณซ้ำได้จาก seed เดิมและข้อมูลตั้งต้นเดียวกัน กติกาทีมรวมฟุตบอล/วอลเลย์บอลใช้ตามทะเบียนเลขทีมกลาง

ระบบใช้การค้นหาแบบสุ่มพร้อมสลับตำแหน่งเพื่อลดต้นทุน จึงรายงานผลที่ค้นพบด้วยจำนวนคู่โรงเรียนที่ได้ร่วมสาย ความถี่ซ้ำสูงสุด และจำนวนชุดสายซ้ำ เมื่อรายการมีผลแข่งขันแล้ว ระบบตรวจผลที่ได้รับผลกระทบก่อนอนุญาตให้เปลี่ยนสาย

## การบันทึกผลข้างสนาม

หน้าผู้จัดเปิดที่รายการพร้อมลงผล เลือกกีฬา วัน รุ่น ประเภท หรือค้นหาชื่อโรงเรียนและรหัสคู่ได้จากหน้ารายการ การ์ดแสดงโลโก้คู่แข่งขันและผลเดิม กด «กรอกผล» เพื่อเปิดเฉพาะหน้าคะแนน ส่วนทะเบียนโรงเรียนและการจัดคิวอยู่ในแท็บ «จัดการทีมและตั้งค่า»

ฟุตบอลและเปตองกรอกคะแนนทั้งสองทีม วอลเลย์บอลและตะกร้อกรอกแต้มทีละเซต ระบบเปิดเซตที่ 3 เมื่อสองเซตแรกเสมอกัน 1–1 และสรุปผู้ชนะก่อนบันทึก ปุ่ม «บันทึกและกรอกคู่ถัดไป» เลือกคู่ว่างตามลำดับวันเวลาในตัวกรองปัจจุบัน โดยข้ามคู่ที่ยังไม่ทราบทีมและคู่ที่บันทึกแล้ว การทดสอบหน้าเว็บใช้สำเนาข้อมูลและตัวเชื่อมข้อมูลในหน่วยความจำแยกจากฐานข้อมูลจริง
